# Rules of Keywords and Identifiers in JavaScript

## 1. Keywords

Keywords are reserved words in JavaScript that have special meanings.

### Rules of keywords

- Keywords have predefined meanings in JavaScript.
- They cannot be used as variable names.
- Keywords are used for specific purposes, such as `if`, `else`, `let`, `const`, and `return`.
- JavaScript keywords are case-sensitive.
- Keywords must be used according to JavaScript syntax.

Example:

```js
let age = 20;
```

## 2. Identifiers

Identifiers are names used for variables, functions, classes, and other program elements.

### Rules of identifiers

- An identifier can contain letters, digits, underscores (`_`), and dollar signs (`$`).
- It cannot begin with a digit.
- It cannot contain spaces.
- It cannot be a reserved keyword.
- Identifiers are case-sensitive (`name` and `Name` are different).
- Special characters such as `@`, `#`, and `%` are not allowed.

Example:

```js
let studentName = "Rahul";
```
