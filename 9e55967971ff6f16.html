Regex to extract an email ID

let msg = "Pramod Dutta is a very handsome man. He has an email ID of pramod@gmail.com, and he is working almost 10 hours per day. Something like";

let email = msg.match(/[\w.+-]+@[\w-]+(?:\.[\w-]+)+/);
console.log(email[0]);   // pramod@gmail.com

How the pattern reads

PartMeansMatches in pramod@gmail.com
[\w.+-]+One or more letters, digits, _, ., + or -pramod
@A literal @@
[\w-]+The domain namegmail
(?:\.[\w-]+)+One or more .something parts, grouped without capturing.com (or .co.in)

Notes

  • Use a regex literal (/.../), not a string. msg.match("...") works, but every backslash then has to be doubled ("\\w").
  • No match gives null, so email[0] would throw. Guard it: const email = msg.match(re)?.[0];
  • All emails: add the g flag. msg.match(/[\w.+-]+@[\w-]+(?:\.[\w-]+)+/g) returns an array of every email, e.g. ["a.b+qa@test-mail.co.in", "x_y@site.org"].
  • Why (?:\.[\w-]+)+ and not \.[\w.-]+: the simpler version also grabs a full stop at the end of a sentence, so "x@y.com." would come out as x@y.com..
  • This is a practical pattern for test data and logs, not a full validator. Real email validation is far more complex; for forms, test what the app accepts.
